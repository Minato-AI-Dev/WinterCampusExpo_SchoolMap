# Winter Campus Expo — 滋賀大学講堂へのアクセス

滋賀大学彦根キャンパスで開催予定の「Winter Campus Expo」にお越しになる方のための、**講堂専用アクセス案内**です。

## サイト

https://minato-ai-dev.github.io/WinterCampusExpo_SchoolMap/

## 内容

- 会場：**滋賀大学彦根キャンパス 講堂**（〒522-8522 滋賀県彦根市馬場1丁目1番1号）
- 滋賀大学経済学部の公式構内図を表示し、**正門21番 → 講堂1番** と **裏側の来客用駐車場22番 → 講堂1番** の2通りを案内
- 彦根駅西口からのアクセス（直行バス・徒歩・タクシー）
- Google マップ、公式構内図、大学公式交通案内へのリンク

**意図的に設置していないもの：** キャンパス内の施設一覧、施設検索、カテゴリフィルター、他施設の案内。

**開催予定：** 2026年12月2日（水）17:00〜（変更の可能性あり）。
